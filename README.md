## 📋 Sobre o projeto | About

**PT-BR:** Plataforma de filmes inspirada no Netflix, construída com JavaScript puro, HTML5 e CSS3. Consome a API pública do TheMovieDB (TMDB) via Fetch API para exibir filmes populares organizados por gênero (Ação, Terror, Comédia e outros), com catálogo atualizado automaticamente, banner dinâmico do filme em destaque e busca em tempo real.

**EN:** Netflix-inspired movie platform built with vanilla JavaScript, HTML5, and CSS3. Consumes TheMovieDB (TMDB) public API via Fetch to display popular movies organized by genre (Action, Horror, Comedy, and more), with an auto-updated catalog, dynamic featured movie banner, and real-time search.

## ⚡ Destaques técnicos | Technical Highlights

- **Consumo de API externa** — integração com TheMovieDB via Fetch API em JavaScript ES6+
- **Catálogo por gênero** — filmes organizados em categorias (Ação, Terror, Comédia e outros) com scroll horizontal estilo Netflix
- **Banner dinâmico** — filme em destaque atualizado automaticamente na página inicial
- **Busca em tempo real** — resultados exibidos dinamicamente conforme o usuário digita, sem recarregar a página
- **JavaScript puro** — sem frameworks, demonstrando domínio de JS vanilla, Fetch API e manipulação do DOM
- **UI responsiva** — interface construída com HTML5 e CSS3, adaptada para diferentes tamanhos de tela
- **Catálogo atualizado** — filmes sincronizados com a API do TMDB em tempo real

## 🔑 Como obter a API Key

1. Crie uma conta em [themoviedb.org](https://www.themoviedb.org/)
2. Acesse **Configurações → API**
3. Solicite uma chave de API gratuita
4. Substitua no código: `const API_KEY = 'sua_chave_aqui'`
