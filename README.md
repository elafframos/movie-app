## 📋 Sobre o projeto | About

**PT-BR:** Aplicação de busca de filmes que consome a API pública do TheMovieDB (TMDB). O usuário digita o nome de um filme e os resultados aparecem em tempo real, sem necessidade de recarregar a página. Interface responsiva construída com JavaScript puro, HTML5 e CSS3.

**EN:** Movie search app that consumes TheMovieDB (TMDB) public API. The user types a movie name and results appear in real time without page reload. Responsive interface built with vanilla JavaScript, HTML5, and CSS3.

---

## ⚡ Destaques técnicos | Technical Highlights

- **Consumo de API externa** — integração com TheMovieDB via Fetch API
- **Busca em tempo real** — resultados exibidos dinamicamente conforme o usuário digita
- **JavaScript puro** — sem frameworks, demonstrando domínio do JS vanilla e do DOM
- **UI responsiva** — layout adaptado para diferentes tamanhos de tela
- **Sem dependências** — projeto leve, sem bibliotecas externas

## 🔑 Como obter a API Key

1. Crie uma conta em [themoviedb.org](https://www.themoviedb.org/)
2. Acesse **Configurações → API**
3. Solicite uma chave de API gratuita
4. Substitua no código: `const API_KEY = 'sua_chave_aqui'`
